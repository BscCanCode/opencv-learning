# OpenCV Practice

This repository contains my practice work while learning **OpenCV with Python**.
It documents my progress from basic image processing to simple real-time detection
using a webcam.

The focus of this repo is understanding OpenCV fundamentals through hands-on
experimentation, not building production-ready systems.

---

## What I Implemented

- Image loading and display
- Grayscale conversion
- Binary and binary inverse thresholding
- Understanding foreground vs background
- Contour detection and drawing
- Polygon approximation using `approxPolyDP`
- Basic shape detection (triangle, square, circle)
- Working with Regions of Interest (ROI)
- Webcam video capture and frame processing
- Face detection using Haar cascades
- Eye detection within face regions
- Basic smile detection and tuning parameters

Each script focuses on learning one concept at a time.

---

## Notes

- Haar cascade detection is sensitive to lighting and may produce false positives
- Smile and eye detection are not always accurate
- Code is written for learning and clarity, not optimization
